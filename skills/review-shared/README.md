# General Review (Shared)

General review requirements and formatting guides used by all review artifacts. Language-specific checklists live in the respective prompts (go-code-review, python-code-review); depend on those prompts to reuse them.

## Files

- `general-review-requirements.md`: Mandatory review behavior across all review artifacts.
- `severity-rubric.md`: Severity classification guidance.
- `output-template.md`: Standard output structure for findings.
- `review-the-review.md`: Final self-validation checklist for completed
  reviews before presenting findings.
